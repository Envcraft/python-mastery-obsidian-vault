# Progress Tracker

## How to Use This Tracker

Update the `status` field in each note's YAML frontmatter as you progress:

```yaml
status: not-started   # Haven't started
status: learning      # Actively reading and understanding
status: practicing    # Writing code, solving exercises
status: reviewing     # Revisiting for retention
status: mastered      # Can explain, implement, debug, apply
```

Then update the table below to match.

**Mastery criteria** — you've mastered a concept when you can:
1. Explain it clearly without notes
2. Implement it from memory
3. Debug common mistakes in it
4. Identify edge cases
5. Apply it in a real project
